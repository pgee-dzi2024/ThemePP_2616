# Система за масова имейл комуникация с асинхронно изпълнение

Уеб приложение, разработено с Python, Django и Django REST Framework, което позволява:

- създаване и управление на маркетинг кампании
- добавяне на получатели
- импорт на получатели от CSV файл
- валидиране на имейл адреси
- изпращане на имейли чрез SMTP
- асинхронна обработка чрез worker нишка
- статуси за всеки получател
- история и лог на изпращанията
- stop/pause функционалност

## Използвани технологии

- Python 3.10
- Django
- Django REST Framework
- HTML/CSS
- Vue.js CDN
- Axios CDN
- threading / queue
- SMTP

## Основни функционалности

### Кампании
- създаване на кампания
- преглед на списък с кампании
- детайли за кампанията
- статистика

### Получатели
- ръчно добавяне на имейли
- импорт от CSV файл
- валидация на имейл адресите

### Изпращане
- изпращане през SMTP
- асинхронно обработване във фонов worker
- retry при временни грешки
- статуси: pending, sent, failed

### Управление
- start на кампания
- pause на кампания
- stop/cancel на кампания

## Структура на проекта

- `DP/DP/` – основни настройки на Django проекта
- `DP/main/` – основното приложение
- `DP/main/models.py` – моделите
- `DP/main/serializers.py` – DRF serializers
- `DP/main/api_views.py` – API views
- `DP/main/api_urls.py` – API маршрути
- `DP/main/services.py` – SMTP логика
- `DP/main/worker.py` – фонов worker
- `DP/main/templates/` – HTML шаблони
- `DP/sample_recipients.csv` – примерен файл за импорт

## Забележка

За да работи изпращането на имейли, е необходимо SMTP настройките в `settings.py` да бъдат попълнени с реални стойности.
